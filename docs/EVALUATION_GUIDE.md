## Reproducing every number

Prerequisites: `examples/private/jw2020.pdf` (the published RFS PDF, not in git) and a
`.env` with an HKUST API key for the two live steps. Everything else replays from cache
or needs no key at all.

```bash
python -m pytest -q                        # 55 tests, no key, no private PDF needed
python scripts/threshold_experiment.py     # threshold table; no key; includes the live
                                           # JW2020 quotes when the private PDF is present
python scripts/run_examples.py --mode live # evaluation.md; cached pairs cost nothing
python scripts/baseline_experiment.py --model gpt-4.1-mini            # baseline transcript
python scripts/baseline_experiment.py --model deepseek/deepseek-v4-flash-0731
```
